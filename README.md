# Sustained Attention to Response Task (SART)

A browser-based sustained attention task that measures accuracy and mean reaction time.

- **Task:** Press spacebar for digits 1–9 except **3** (no-go).
- **Fixation dot** between trials to reduce carryover.
- **Output:** Mean RT, go/no-go accuracy, optional CSV export.

Open `index.html` in a browser to run locally, or use the Vercel deployment.
